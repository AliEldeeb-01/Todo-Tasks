# Todo App

A client-side task and planning application built with React and Vite. Manage tasks, track progress, and organize plans with details. Data is saved in the browser using `localStorage`.

## Features

### Tasks
- Add and delete tasks.
- Mark tasks as complete or active.
- Filter tasks by all, active, or completed.
- View total, completed, and remaining task counts.
- Clear all completed tasks.
- Save tasks, the current input, and the selected filter in browser storage.
- Show a custom animated empty state.

### Plans
- Create plans with a title.
- Add or edit plan details.
- Delete plans with a confirmation prompt.
- Save plans in browser storage.

## Technology

- React
- Vite
- Tailwind CSS
- CSS
- styled-components
- SweetAlert2
- Oxlint
